# Acceptance-Criteria Readiness Rubric

Momo uses this rubric as a business/readiness observation. It is not a
Lifecycle transition guard and cannot satisfy an authoritative obligation.

Assess all four dimensions:

1. Non-empty: the intended outcome is stated.
2. Testable: observable evidence can prove or disprove it.
3. Enumerated: distinct requirements are separately identifiable.
4. Functional-requirement coverage: the criteria trace to the governing need.

Record each result and supporting evidence. When a dimension fails, Momo may
delegate refinement if the legal frontier permits that action. Submit the
assessment as an observation/evidence input, then refetch Lifecycle. Only
Lifecycle decides whether the resulting obligations and frontier change.
