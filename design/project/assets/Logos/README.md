# Logos

The mark is 33 set against its mirror, four half-discs with the lower-right quadrant lit. Each file has fixed inks, because an `<img>` cannot inherit colour.

- `33god-mark.svg`: for light grounds. Ink `#1a201b` (`ink`, light) and ochre `#835d13` (`ochre`, light).
- `33god-mark-dark.svg`: for dark grounds. Ink `#e3e8e3` (`ink`, dark) and ochre `#d8b36e` (`ochre`, dark).
- `33god-mark-mono.svg`: one ink, `#1a201b`, for anywhere only one colour prints.
- `33god-lockup.svg` and `33god-lockup-dark.svg`: the mark with "33GOD" in Newsreader 500, outlined so it needs no font. Inks as above.
- `33god-app-icon.svg`: the launcher, favicon and Telegram tile, with the dark mark on a `ground` (dark) tile and a 96/512 corner radius.

Clear space equals one half-disc width. The minimum size is 12px for the mark and 16px tall for the lockup. Never recolour, rotate or animate the mark.
