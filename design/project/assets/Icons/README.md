# Icons

The Lucide outlines the kit uses, re-stroked at 1.75 in `ink` (`#1a201b`) for display here. In product UI, `Icon` inlines the same paths with `currentColor`: 14px in rows, 16px in controls. Add new icons from Lucide only, at the same stroke.

| File | `Icon` name | Used for |
|---|---|---|
| `copy.svg` | `copy` | Copy actions |
| `check.svg` | `check` | Copy confirmation |
| `external-link.svg` | `external` | A Ref that opens elsewhere |
| `chevron-right.svg` | `chevronRight` | Disclosure, closed |
| `chevron-down.svg` | `chevronDown` | Disclosure, open |
| `square-terminal.svg` | `pane` | A zellij pane |
| `git-commit-horizontal.svg` | `commit` | A commit |
| `git-branch.svg` | `branch` | A branch or worktree |
| `search.svg` | `search` | Jump to |
| `x.svg` | `x` | Close, clear |
| `corner-down-left.svg` | `enter` | The enter key |
| `rotate-ccw.svg` | `restart` | Restart |
| `pause.svg` | `pause` | Pause the feed |
| `play.svg` | `play` | Resume the feed |
| `filter.svg` | `filter` | The subject filter |
| `ticket.svg` | `ticket` | A Plane ticket |
| `box.svg` | `unit` | A systemd unit or container |
