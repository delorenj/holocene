# Kbd

A keyboard shortcut, written as a string like `mod+k`, where `mod` renders as the command glyph on macOS and Ctrl elsewhere.

## The house shortcuts

| Keys | Action |
|---|---|
| `mod+k` | Jump to anything |
| `/` | Focus the subject filter |
| `j` / `k` | Next or previous row |
| `enter` | Open, or go to the row's pane |
| `esc` | Close, clear, disarm |

## Rules

- Show the shortcut on the control it triggers (`Button kbd`), not in a help page.
- One key per action. No chords beyond a single modifier.
