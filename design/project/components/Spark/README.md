# Spark

A trend without axes: a 2px line in ink-3 over a 10% wash, where the latest value is the only coloured mark.

## Props

- `values` (required).
- `width` and `height`.
- `state` colours the endpoint only.
- `label` is the accessible description.

## Rules

- Use it inside a `Reading` or a row, never as a chart. If the reader needs values, use `Strata` or a table.
- The line never takes the state colour. Text and lines stay in ink tokens.
